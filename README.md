I like building systems that solve real problems: the kind that run in production, with people relying on them every day, not just in a nice demo.

These days I spend most of my time on **putting AI inside real workflows without losing control**: the right context, clear limits and end-to-end traceability. AI should help people decide, not decide on its own.

### 🤖 AI with a human in the loop

I don't just talk about this, I work this way. I coordinate a team of AI agents that write specs, open draft PRs, run visual QA and comment the results with screenshots, and nothing reaches production until a human approves it. Every agent works with shared memory ([AI Memory](https://railway.com/deploy/ai-memory)), clear scope and an audit trail.

### 🧭 How I work

I start from the spec, not the code. First the rules of the system, then the requirements, then the design, and only then the implementation, using AI to speed things up, never as a replacement for thinking.

- **Simple > clever.** "Genius" code usually turns into debt.
- **Everything that matters is traceable.** Logs, traces and metrics from day one.
- **The model only sees what it needs to see.** Minimum data exposure.
- **Cost is a requirement.** You can save on infrastructure without giving up reliability.
- **Think long term.** A good system is one you can maintain and evolve.

### 🛠️ Day to day

TypeScript in strict mode (and no `any`, please), Node.js and Bun on the backend, React and Tailwind on the front end. Zod for contracts, idempotent APIs for critical operations, and event-driven architecture when it actually makes sense. Observability with OpenTelemetry, New Relic and PostHog.

### 🤖 IA com humano no circuito

Não é só discurso, é como eu trabalho. ### 🧭 Como eu trabalho

Começo pela especificação, não pelo código. Primeiro as regras do sistema, depois os requisitos, depois o desenho da solução, e só então a implementação, usando IA como acelerador, nunca como substituto do raciocínio.

- **Simples > esperto.** Código "genial" costuma virar dívida.
- **Tudo que importa é rastreável.** Logs, traces e métricas desde o primeiro dia.
- **O modelo só vê o que precisa ver.** Menor exposição de dados possível.
- **Custo é requisito.** Dá pra economizar infraestrutura sem abrir mão de confiabilidade.
- **Pensar no longo prazo.** Sistema bom é sistema que dá pra manter e evoluir.
